## 简介

HyperThermal 是一个适配 HyperOS / MIUI 全版本的动态温控模块。通过动态替换 MIUI 云温控配置文件，实现在充电、游戏等不同场景下自动切换温控策略，支持旁路供电和电流控制。提供 WebUI 可视化界面，无需手动编辑配置文件。

---

## 安装要求

- KernelSU（推荐 v0.6.0 以上，支持 WebUI）或 APatch
- HyperOS 1.x / 2.x / 3.x，或 MIUI 14+
- 设备需支持 MIUI 云温控（`mi_thermald` 进程存在）
- Root 权限

---

## 安装步骤

1. 将 `HyperThermal-v1.0.0.zip` 传输到手机存储
2. 打开 **KSU 管理器** → **模块** → 右下角 **+** 按钮
3. 选择 zip 文件安装，等待安装完成
4. **重启手机**
5. 重启后在 KSU 管理器模块列表中，点击 HyperThermal 右侧的 **⚙️ 设置图标** 打开 WebUI

> 若之前安装过旧版 MiuiVariableThermal 模块，安装时会自动迁移游戏应用列表。建议安装完成后**禁用旧模块**，避免冲突。

## WebUI 界面说明

### 顶部状态栏

实时显示设备当前状态，每 3 秒自动刷新：

| 指标 | 说明 |
|------|------|
| 温度 | 电池温度（°C），≥45°C 红色，≥38°C 橙色，正常绿色 |
| 电流 | 充电电流（mA），负值表示放电 |
| 电量 | 当前电池电量（%） |
| 当前模式 | 正在生效的温控模式 |

设备信息栏显示：机型 / 平台 / 系统版本 / 温控进程名。

## 功能详解

### 一、模块总开关

关闭后模块停止所有温控干预，恢复系统默认温控策略。

---

### 二、充电场景

**充电时启用温控**：开启后，插入充电器时自动切换到指定温控档位。

#### 温控档位说明

档位越高，对充电速度和性能的限制越严格：

| 档位 | 充电温度范围 | 适用场景 |
|------|------------|---------|
| 无限制（零档） | 无限制，高温也全速充电 | 追求最快充电速度 |
| 一档 | 45~55°C 特快充电 | 日常快充 |
| 二档 | 40~50°C 快速充电 | 平衡充电速度与温度 |
| 三档 | 35~45°C 中速充电 | 注重电池健康 |
| 四档 | 30~40°C 慢速充电 | 长期保养 |
| 五档 | 25~35°C 特慢充电 | 夜间慢充保护 |
| 系统默认 | 使用系统原始温控 | 不干预 |

#### 亮屏充电档位
插充电器且屏幕亮着时使用的档位。

#### 息屏充电档位
插充电器且屏幕熄灭时使用的档位。通常设置比亮屏更高的档位（更严格），保护夜间充电时的电池。

**推荐配置**：亮屏 → 无限制，息屏 → 三档

#### 定时切换
在指定时间段内自动切换到另一个档位。

- **开始时间 / 结束时间**：填 0~23 的整数（小时），支持跨午夜（如 23 到 7 表示晚上 11 点到早上 7 点）
- **时段档位**：该时间段内使用的档位
- 两个时间相同时表示关闭定时功能

**示例**：23 → 7 → 五档，表示晚上 11 点到早上 7 点使用五档慢充保护电池。

---

### 三、游戏场景

**游戏模式**：开启后，当检测到前台应用在游戏列表中时，自动切换到游戏温控档位。

#### 游戏温控档位
游戏时使用的温控档位，建议设为**无限制**以保证性能不受温控限制。

#### 游戏时旁路供电
游戏时若正在充电，自动开启旁路供电（充电器直接供电，停止对电池充电），降低电池温度，避免边充边玩导致过热。

#### 锁定刷新率
游戏时锁定屏幕刷新率（填写设备支持的刷新率数值，如 120、144），离开游戏后自动恢复。填 0 表示不锁定。

> 注意：此功能无法解决游戏内部的锁帧问题（通常由云控导致）。

#### 游戏应用列表
添加需要触发游戏模式的应用包名。

**添加方法**：在输入框填入包名（如 `com.tencent.tmgp.sgame`），点击**添加**按钮。

**常用游戏包名参考**：

| 游戏 | 包名 |
|------|------|
| 王者荣耀 | com.tencent.tmgp.sgame |
| 和平精英 | com.tencent.tmgp.pubgmhd |
| 原神 | com.miHoYo.Yuanshen |
| 英雄联盟手游 | com.tencent.lolm |
| 崩坏：星穹铁道 | com.HoYoverse.Starrail |
| 明日方舟 | com.hypergryph.arknights |

---

### 四、旁路供电

旁路供电时，充电器直接为手机供电，**停止对电池充电**，有效降低电池温度。适合高温充电或长时间游戏时使用。

> 效果因机型而异，部分机型仍会有少量电流（500mA 左右）流向电池。

#### 温度旁路
- **开启温度**：电池温度达到此值时自动开启旁路（建议 43~48°C）
- **关闭温度**：电池温度降至此值时自动关闭旁路（建议比开启温度低 3~5°C）
- 填 0 表示关闭温度旁路

**示例**：开启 45°C，关闭 40°C → 电池超过 45°C 自动旁路，降到 40°C 以下恢复正常充电。

#### 电量旁路
电量达到指定值时自动开启旁路（如填 80，则电量 ≥80% 时停止充电，仅供电）。填 0 表示关闭。适合不想充满电保护电池的场景。

#### 手动旁路
手动开关，立即生效。开启后充电器直接供电，关闭后恢复正常充电。

**优先级**：温度旁路 > 手动旁路 > 电量旁路 > 游戏旁路

---

### 五、电流控制

限制最大充电电流（单位：微安 μA）。

| 功率 | 电流值（μA） |
|------|------------|
| 不限制 | 0 |
| 约 18W | 3000000 |
| 约 33W | 6000000 |
| 约 67W | 12000000 |
| 约 120W | 22000000 |

- **充电电流限制**：填 0 表示不限制，填具体数值则限制最大充电电流
- **设备最大充电电流**：填写设备支持的最大充电电流，旁路关闭时用于恢复电流（默认 22000000 对应 120W）

> 此功能与其他控制电流的模块/软件冲突，请勿同时使用。

---

### 六、普通场景

非充电、非游戏时使用的温控模式。通常保持**系统默认**即可。若希望日常使用也解除温控限制，可设为**无限制**。

---

## 配置生效时间

WebUI 保存后，模块每 **3 秒**轮询一次配置，最多 3 秒内生效。

若需立即生效，可在 WebUI 中将**模块总开关**关闭再开启。

## 常见问题

**Q：安装后模块显示"机型不支持"？**

A：设备不支持 MIUI 云温控机制（非小米/红米设备，或系统版本过旧）。

**Q：WebUI 打开后显示"加载中"不变化？**

A：模块可能还未完成启动（开机后约 10 秒），等待后刷新页面。

**Q：修改档位后没有效果？**

A：检查"充电时启用温控"开关是否已开启；确认设备处于充电状态；等待 3~5 秒让轮询生效。

**Q：旁路供电开启后电量还在上涨？**

A：部分机型旁路供电仍有小电流，属正常现象。可尝试开启"电流控制"并设置较小电流值配合使用。

**Q：与其他模块冲突怎么办？**

A：本模块与控制充电电流类模块冲突（如充电管理类模块）。建议禁用冲突模块，保留本模块。旧版 MiuiVariableThermal 必须禁用。

**Q：如何完全卸载？**

A：在 KSU 管理器中删除模块，重启后自动恢复系统默认温控。

## 文件结构说明

```
/data/adb/modules/HyperThermal/
├── config/
│   ├── settings.json     # 用户配置（WebUI读写）
│   ├── runtime.json      # 运行时设备信息
│   ├── status.json       # 实时电池状态
│   ├── current_mode      # 当前温控模式
│   └── bypass_manual     # 手动旁路状态
├── thermal/
│   ├── 1~5/thermal-scene.conf  # 各档位温控配置文件
│   └── ...
├── t_blank               # 零档温控文件（无限制）
├── t_bypass_0/1          # 旁路供电温控文件
├── t_map                 # thermal-map配置
├── thermal_list          # 设备温控文件列表
├── log.log               # 运行日志
└── webroot/index.html    # WebUI界面
```
